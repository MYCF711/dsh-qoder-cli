# 设计预览（Preview）

这些是 Qoder 卡片的**静态 HTML 预览**，用于展示设计意图、便于二次开发参考。
每个文件都是**单文件零依赖**，双击用浏览器打开即可交互。

| 文件 | 内容 |
|---|---|
| `qoder-card-interactive.html` | **完整交互预览**——4 个 tab 可切换（账号管理 / 可选模型 / 资源明细 / 用量统计），含账号卡片展开、资源包明细、按模型分类条形图 |
| `theme-matrix.html` | **主题适配矩阵**——3 种主题色 × 3 种背景 = 9 种组合对照，用于验证主题 token 的跟随效果 |
| `dsh-ui-glossary.html` | **DSH UI 术语速查（中文配图）**——色彩 token / 组件术语 / 交互状态 / 布局术语，每个配渲染示例 + 官方名称 |
| `qoder-card-preview-v4.html` | 历史版本（早期设计稿，保留作对照） |

## 与 `lib/client.js` 的关系

预览是**设计意图的表达**，不是运行时代码。实际实现见 `lib/client.js` 的 `QoderPluginCardBody`。

**样式值应保持一致**：预览里的 grid 列定义、颜色 token、间距等取自实际实现。若两者不一致，**以 `lib/client.js` 为准**。

## 二次开发提示

- 所有预览内的样式值都标注了实际使用的 CSS 变量（`--dsw-alias-*`），可直接照抄到你的插件
- 主题适配部分说明了**哪些颜色应该跟随主题**（中性色 → token）、**哪些不应该**（语义色：成功绿/警告琥珀/错误红）
- 演示数据已脱敏（账号名 `demo-user`、邮箱 `demo@example.com`）
