DSH UI 术语速查手册

配图配文字 · 左边是渲染效果 · 右边是官方名称 + token + 用途说明

§1 色彩 Token（--dsw-alias-*）

DSH 的颜色不直接写色值，全部通过 CSS 变量引用，自动适配亮/暗主题。

--dsw-alias-brand-primary → 品牌色（按钮/开关/tab 下划线）
--dsw-alias-label-primary → 主要文字色
--dsw-alias-label-secondary → 次要文字色
--dsw-alias-label-tertiary → 三级文字色
--dsw-alias-bg-layer-1 → 底层背景色
--dsw-alias-bg-layer-3 → 卡片/面板底色
--dsw-alias-border-l4 → 边框色
--dsw-alias-label-error → 错误/危险色

§2 组件术语

开关（Switch）

 
Switch / 开关
checked / unchecked
绿色=选中(checked)，灰色=未选中(unchecked)。选中时 brand 色底+白点右滑。

按钮（Button）

 
Button / 按钮
primary（brand 实底）/ ghost（描边透明底）
primary=brand 色实底白字（登录/签到等主操作）；ghost=透明底描边（刷新/取消等次操作）。

徽章（Chip）

错峰 4 折 不可用 已过期
Chip / 徽章（药丸标签）
promo=绿色实底 / degraded=琥珀描边 / danger=红色实底
促销=绿色实底；不可用=琥珀描边幽灵样式；已过期=红色实底。三种视觉重量表示三种信息优先级。

头像（Avatar）

M
Avatar / 头像
avatarTone(name) → rgba 品牌色系淡底
34px 圆形，首字母大写，底色按名字 hash 从六色品牌色系取色。有 avatar_url 时优先显示图片。

状态点（Status Dot）

 在线
Status Dot / 状态点
绿=在线/正常，红=异常
8px 圆点 + 淡色光晕（box-shadow），放在名称旁表示连接状态。

进度条（Progress Bar）

Progress Bar / 进度条
progressTrack（轨道）+ progressFill（填充）
4px 高圆角轨道，brand 色填充表示用量/进度百分比。

Tab 导航（二级菜单）

Tab Bar / 标签导航
active → border-bottom 2px brand 色
下划线高亮当前选中项，非选中项 opacity 0.65。用于卡片内二级菜单切换。

输入框（Text Input）

Text Input / 文本输入框
border + bg 半透明
用于搜索/路径输入等场景。

下拉选择（Select）

Select / 下拉选择框
用于思考档位/上下文档位等选项
模型行里选思考深度（关闭/低/中/极高）和上下文窗口（200K/400K/1M）。

§3 交互状态

交互状态一览
hover = 鼠标悬停（行衬底高亮）
active = 当前选中的 tab / 当前账号
checked = 开关打开
disabled = 禁用（按钮变灰 opacity 0.55 + cursor default）
busy = 请求进行中（全部按钮禁用防双击）
focused = 键盘焦点（border 变 brand 色）

§4 布局术语

布局方式
grid = 网格布局（固定列宽对齐，如模型行 34px/1fr/96px/100px/56px）
flex = 弹性布局（自适应宽度，如按钮行）
gap = 元素之间的间距
padding = 内边距（卡片内容与边框的距离）
margin = 外边距（元素与其他元素的距离）

§5 我们卡片的对照速查

"那个绿色的开关" → Switch 组件，checked 时 brand 色底
"那个黑的登录按钮" → primary Button，brand 实底
"那个绿的小标签" → Chip（promo 徽章），绿色实底
"那个描边的不可用标签" → Chip（degraded 徽章），琥珀描边幽灵样式
"那个圆圈头像" → Avatar，34px 圆形 + avatarTone 品牌色淡底
"那个小绿点" → Status Dot，8px 绿色圆点 + 淡绿光晕
"那个横条进度" → Progress Bar，4px 轨道 + brand 色填充
"上面那排标签" → Tab Bar，下划线高亮当前选中项
